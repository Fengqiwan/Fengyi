语义化标签使用指南

2026-05-12 · 前端开发 · 阅读约5分钟

HTML5 引入了大量语义化标签，它们让文档结构更清晰、可访问性更好、SEO 更友好。下面是各标签的核心作用：

块级语义标签一览

  • header — 页面或区块的头部
  • nav — 导航链接集合
  • main — 页面主体内容（唯一）
  • article — 独立的内容单元
  • section — 主题性分组
  • aside — 侧边补充内容
  • footer — 页面或区块的底部

为什么不用 div 替代？

  1. 屏幕阅读器能识别语义标签，提升无障碍体验
  2. 搜索引擎能更准确理解内容结构
  3. 代码可读性和可维护性大幅提升

Flexbox 布局实战技巧

2026-05-10 · CSS布局 · 阅读约3分钟

Flexbox 是现代 CSS 布局的核心工具，掌握以下属性组合可以解决 90% 的布局需求。

常用属性速查

  • flex: 1 — 自动填充剩余空间
  • align-items: stretch — 子项等高
  • min-width: 0 — 允许内容收缩
  • flex-shrink: 0 — 禁止被压缩
  • gap — 替代margin实现间距

实战案例分析

在页尾布局中，我们使用 flex + stretch 实现左右等高，用 flex-shrink:0 保护二维码不被压缩，用 min-width:0 + overflow-wrap 防止极窄屏溢出。这些技巧的组合使用是 Flexbox 的精髓所在。

合理组合这些属性，配合媒体查询实现响应式，可以覆盖绝大多数业务场景。关键是理解每个属性的作用原理，而非死记硬背。

响应式设计核心原则

2026-05-08 · 响应式 · 阅读约4分钟

响应式设计的目标是让网页在任何设备上都能提供良好的用户体验，从320px的小屏手机到2560px的超宽显示器。

移动优先策略

移动优先（Mobile First）意味着先编写移动端样式作为基础，然后通过 min-width 媒体查询逐步增强桌面端体验。这种方式确保了核心内容在任何设备上都可访问。

  • 基础样式 → 适用于所有屏幕
  • @media (min-width: 768px) → 平板及以上增强
  • @media (min-width: 1024px) → 桌面端完整体验

断点选择与内容适配

断点不应该根据特定设备选择，而应该根据内容何时"断裂"来决定。当内容在某个宽度下开始显示不佳时，就是设置断点的时机。

常用断点参考：480px（大屏手机）、768px（平板）、1024px（小型桌面）、1200px（标准桌面）。但这些只是参考，实际项目应根据设计稿和内容灵活调整。
