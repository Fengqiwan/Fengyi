语义化标签使用指南

2026-05-12 · 前端开发 · 阅读约5分钟

HTML5 引入了大量语义化标签，它们让文档结构更清晰、可访问性更好、SEO 更友好。下面是各标签的核心作用：

<section>

块级语义标签一览

  • header — 页面或区块的头部
  • nav — 导航链接集合
  • main — 页面主体内容（唯一）
  • article — 独立的内容单元
  • section — 主题性分组
  • aside — 侧边补充内容
  • footer — 页面或区块的底部
<section>

为什么不用 div 替代？

  1. 屏幕阅读器能识别语义标签，提升无障碍体验
  2. 搜索引擎能更准确理解内容结构
  3. 代码可读性和可维护性大幅提升

Flexbox 布局实战技巧

2026-05-10 · CSS布局 · 阅读约3分钟

Flexbox 是现代 CSS 布局的核心工具。掌握以下属性组合可以解决 90% 的布局需求：

<section>

常用属性速查

  • flex: 1 — 自动填充剩余空间
  • align-items: stretch — 子项等高
  • min-width: 0 — 允许内容收缩
  • flex-shrink: 0 — 禁止被压缩
  • gap — 替代margin实现间距

合理组合这些属性，配合媒体查询实现响应式，可以覆盖绝大多数业务场景。
